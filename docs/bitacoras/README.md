## Criterio de registro

La bitácora distingue evidencia de Git, resultados de pruebas, decisiones conversacionales y pendientes. Las fechas sin evidencia se mantienen como pendientes; no se completan por inferencia. Los archivos visuales y el DOCX son entregables de apoyo, no sustituyen el registro Markdown versionado.

## Convenciones de cada día

- **Objetivo:** qué se intentó resolver.
- **Trabajo realizado:** cambios o análisis con evidencia.
- **Problemas:** bloqueos, inconsistencias o fallas observadas.
- **Solución:** corrección aplicada o decisión tomada.
- **Pruebas:** validaciones ejecutadas o pendientes.
- **Decisiones:** reglas que quedaron establecidas.
- **Pendientes:** trabajo no confirmado o que requiere validación posterior.
